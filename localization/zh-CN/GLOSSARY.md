# zh-CN glossary

Nouns, place names, spells and items follow the official vanilla 1.12.1 zhCN client (for example Westfall = 西部荒野, Molten Core = 熔火之心, Zul'Gurub = 祖尔格拉布, Ruins of Ahn'Qiraj = 安其拉废墟, Duskwood = 暮色森林, Frostbolt = 寒冰箭).
